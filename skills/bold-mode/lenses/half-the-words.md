# Half the words

**Works for:** writing, design

**The move:** Cut the text or interface to half its size, then see what was actually needed.

**Ask:**
- Which sentences or elements repeat something already said?
- What does the reader need in the first five seconds?
- If only one thing survived, which one?

**Example:** A 600-word README intro → a one-line pitch, a 3-line install, and one example.

**Watch out:** Halving can drop important nuance. Compare against the goals checklist, not against length alone.
