# Lenses

A lens is one way of looking at a problem that tends to produce a bold or wild idea. During the Diverge step, Claude reads 2-3 lenses that fit the problem.

Each lens is one short markdown file. **Adding a lens is the easiest way to contribute** — see `CONTRIBUTING.md` at the repo root.

## Template

```markdown
# <Lens name>

**Works for:** code | architecture | design | writing (pick what applies)

**The move:** one sentence describing the reframe.

**Ask:**
- question 1
- question 2
- question 3

**Example:** before → after, two or three lines.

**Watch out:** when this lens leads somewhere bad.
```
