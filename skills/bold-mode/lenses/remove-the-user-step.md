# Remove the user step

**Works for:** design, writing

**The move:** Find a step the user (or reader) must take and make it unnecessary, instead of making it easier.

**Ask:**
- What does the user have to type, choose, or remember that the system already knows?
- Which question could have a good default instead?
- What would happen if this screen or paragraph did not exist?

**Example:** A three-field sign-up form → email only; the rest is asked later, when it is needed.

**Watch out:** Removing a step can remove consent or a safety check. Keep those.
