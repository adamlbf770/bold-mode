# bold-mode

**הסיכון מותר ברעיון, לא בשטח הפגיעה.**

פלאגין ל-Claude Code שנותן ל-Claude לנסות את הרעיון הנועז, כמו שכתוב, מחיקת שכבה שלמה או "מה אם זה לא היה קיים", בלי לסכן את הקוד שעובד. כל ניסוי רץ בעותק מבודד, בתקציב צעדים קשיח, ונגמר בטבלת השוואה כנה מול המצב הקיים.

## מה יש בפנים

- **סקיל `bold-mode`:** בידוד, מדידת בסיס, שלושה רעיונות (בטוח, נועז ופרוע), בנייה, מדידה, דוח והעברה לסקירה.
- **11 עדשות:** דרכי חשיבה קצרות שעוזרות למצוא רעיון שאינו המובן מאליו.
- **hook שומר:** פעיל רק בזמן ריצה נועזת. הוא:
  - סופר צעדים ועוצר כשנגמר התקציב (ברירת מחדל 25),
  - חוסם עריכה של הקבצים המקוריים,
  - חוסם force-push, דחיפה ל-main, פרסום, דיפלוי ומחיקת נתונים.
- **פקודת `/bold`:** להפעלה בשורה אחת.

## התקנה

/plugin install bold-mode@bold-mode

## מתי לא להשתמש

תיקונים קטנים, באגים, שגיאות כתיב, ריפקטור שגרתי, או קוד יציב שעובד.

## הגדרות

- `BOLD_MODE_BUDGET`: מספר הצעדים המקסימלי (ברירת מחדל 25).
- `BOLD_MODE_GUARD=off`: מבטל את כל החסימות.

## מגבלות

ה-hook רואה קריאות לכלים, לא כוונות. פקודה שכותבת לקובץ המקורי דרך הפניה (`>`) לא תיתפס. ההגנה העיקרית היא הוראות הסקיל והעותק המבודד, וה-hook הוא חגורת בטיחות.
